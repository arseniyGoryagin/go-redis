## A Redis Server compatible in memory database using RESP 2 protcol built in golang. 

Support ping, get, set, hset, hget

Inspired by the https://www.build-redis-from-scratch.dev/en/implementing-commands

### Installation and  Running

- Clone repository
```bash
git clone [git@github.com:arseniyGoryagin/go-redis.git](https://github.com/arseniyGoryagin/go-redis.git)
```

- Enter repository folder
```bash
cd go-redis 
```

- Run with go
```bash
go run main.go
```
